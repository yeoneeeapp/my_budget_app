# 나만의 가계부

개인용 가계부 앱 (React + Vite + PWA)

## 로컬에서 실행해보기

```bash
npm install
npm run dev
```

## 배포하기 (추천: Vercel)

1. 이 폴더를 GitHub 저장소에 올리기 (새 저장소 생성 후 push)
2. https://vercel.com 에서 GitHub 로그인 → "New Project" → 방금 올린 저장소 선택
3. 별도 설정 없이 "Deploy" 클릭 (Vite 프로젝트는 자동으로 인식돼요)
4. 배포 완료되면 `https://프로젝트이름.vercel.app` 같은 주소가 생겨요

## 안드로이드에 앱처럼 설치하기 (PWA)

1. 위에서 받은 주소를 안드로이드 폰의 크롬 브라우저로 열기
2. 오른쪽 위 메뉴(⋮) → "홈 화면에 추가" 선택
3. 홈 화면에 아이콘이 생기고, 눌러서 실행하면 전체화면 앱처럼 열려요

## 데이터 저장

이 버전은 브라우저의 `localStorage`에 데이터를 저장해요. 즉:

- **같은 브라우저·같은 폰**에서는 앱을 껐다 켜도 데이터가 유지돼요
- 브라우저 데이터를 지우거나 다른 기기/브라우저로 접속하면 데이터는 보이지 않아요 (기기별 저장이에요)
- 나중에 여러 기기에서 동기화하고 싶다면 실제 서버/데이터베이스 연동이 추가로 필요해요
